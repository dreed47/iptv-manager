How it works

Each HDHomeRun channel has a tvg-id from your M3U playlist. The EPG builder tries to match this to a source channel ID in the EPG XML (e.g. cnn.us, espn.us).

If auto-matching fails or picks the wrong show data, enter the correct EPG source ID here. Leave blank to use auto-matching.

To find valid EPG source IDs, look at your generated EPG and search for <channel id="..."> values in the source XML.
